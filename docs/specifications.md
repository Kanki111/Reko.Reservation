# プロジェクト仕様書

## 概要
**プロジェクト名**: Neko Reservation Server  
**目的**: 猫のサロン予約システム  
**対象**: 猫専門のペットサロンの予約管理・顧客管理  
**業務内容**: 猫のグルーミング・トリミングサービス  
**開発開始**: 2025年12月

## 業務仕様

### サロンの基本情報
- **対象動物**: 猫専門
- **サービス内容**: グルーミング、トリミング、シャンプー等
- **営業形態**: 予約制サロン
- **施術体制**: 複数スタッフによる対応  

## 技術仕様

### システム構成
- **フレームワーク**: Laravel 11.x
- **言語**: PHP 8.2
- **フロントエンド**: Blade テンプレート + CSS + JavaScript
- **データベース**: MySQL 8.0 (cat_salon)
- **インフラ**: Docker Compose (Nginx + PHP-FPM + MySQL)
- **外部連携**: LINE Bot API

### 開発環境
- **コンテナ**: Docker Compose
- **タイムゾーン**: Asia/Tokyo
- **文字コード**: UTF-8 (utf8mb4_unicode_ci)

## 機能仕様

### 🟢 実装済み機能

#### 0. LINE予約システム基盤
- **LINE Messaging API連携**: 予定
- **LINE ID取得**: Messaging API経由でLINEユーザーIDを取得
- **データ管理**: `line_user`テーブルでLINE IDと顧客アカウントを紐付け
- **将来連携**: ユーザーログイン機能とLINEアカウントの紐付け

#### 1. 予約カレンダー表示
- **URL**: `/reservation`
- **コントローラー**: `ReservationController@index`
- **機能**:
  - 週間カレンダー形式での空き状況表示
  - スタッフ別スケジュール確認
  - 時間帯: 10:00〜18:30 (30分刻み)
  - 予約可能/満席表示 (○/× マーク)
  
- **データ連携仕組み**:
  - **マスター情報**: reservationテーブル (menu_id + staff_id + 開始時間)
  - **スロット管理**: reservation_slotテーブル (30分おきの占有状況)
  - **所要時間**: menu.duration_minutesから自動計算
  - **○×判定**: reservation_slotの存在で空き状況を判断

#### 2. メニュー・料金表示
- **場所**: 予約ページ内メニューセクション
- **内容**:
  - コースメニュー (シャンプー/シャンプーカット等)
  - オプションメニュー (クレンジング等)
  - 毛玉料金・トリマー2人料金の説明
- **所要時間のバリエーション** (menuテーブルのduration_minutesに分数で格納):
  - 30分メニュー: `duration_minutes = 30` (短時間コース)
  - 1時間メニュー: `duration_minutes = 60` (標準グルーミング)
  - 1.5時間メニュー: `duration_minutes = 90` (本格グルーミング)
  - 2時間メニュー: `duration_minutes = 120` (フルコース)
  - **スロット計算**: `duration_minutes ÷ 30 = 必要スロット数`

#### 3. 予約フロー説明
- **URL**: `/flow` 
- **コントローラー**: `FlowController@index`
- **内容**: STEP形式での予約〜施術完了までの流れ

#### 4. LINE連携機能
- **実装状況**: フロントエンド側実装済み
- **機能**: 
  - 予約時間選択後のLINEメッセージ自動生成
  - LINE アプリへの遷移機能

#### 5. レスポンシブ対応
- **対応範囲**: 全ページ
- **ブレイクポイント**: 768px (タブレット/スマートフォン)

## データ連携

### スタッフデータ
- **定義**: 猫のグルーミング・トリミングを行う施術者
- **職種**: トリマー、グルーマー等の施術スタッフ
- **activeフラグ**: 現在出勤中で担当可能かどうかを表す
  - `1`: 出勤中・担当可能
  - `0`: 不在・担当不可
- **取得**: `Staff::active()->get()` (担当可能なスタッフのみ)
- **表示**: 予約ページでのスタッフ選択ボタン
- **用途**: 施術担当者の指定、スケジュール確認

### 週間カレンダー
- **基準日**: `$targetDate = "2025-11-29"` (現在は固定)
- **計算**: Carbon で月曜開始の週間計算
- **時間帯**: 10:00-18:30 (30分刻み、計18スロット)

## 外部連携

### LINE連携
- **方式**: URL スキーム (`line.me/R/msg/text/`)
- **メッセージ形式**:
  ```
  ネコサロン予約希望
  
  日付: 2025/11/29
  時間: 10:00
  担当者: スタッフ名
  
  こちらの時間でご予約をお願いします。
  ```
